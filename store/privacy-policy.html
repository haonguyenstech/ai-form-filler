Privacy Policy

AI Form Filler — Chrome extension

Last updated: 6 August 2026

AI Form Filler generates plausible test data for the form on the page you are looking at. To do that it asks an AI provider of your choosing to invent a value for each field. This page describes exactly what is sent, what is not, and where it goes.

What is transmitted

For each field on the page, the extension sends a description of the field — never the data already in it:

Sent to the AI providerNever sent
The field's label, name and placeholder Values already present in the fields
Its type, whether it is required, and its format rules (maxLength, minLength, pattern, min/max/step) The page's text, headings or other content
For a dropdown, the list of option labels The page URL, your cookies, your browsing history
Any instruction you type into the extension Anything from other tabs or other sites
A made-up person to fill as (name, email, address…) and the chosen data locale, generated locally for each fill
If the page rejects a value: that value (one the model itself produced) and the page's error message for that field, so the model can correct it Password and file inputs — these are not read, not filled, and not included in the request at all

The extension makes one network request per fill — two if the page rejects some of the values and they are sent back for correction —, addressed to OpenRouter. It contains no analytics, no telemetry, no crash reporting and no server operated by this project. The word fetch appears twice in the entire source, both times pointing at the OpenRouter endpoint.

Where it goes

Only to OpenRouter (openrouter.ai), using the API key you enter in Settings, and on to the model provider you choose there. OpenRouter and each model provider handle the request under their own privacy terms, which this project does not control. Please read them.

Two things you should know before using the free models.

1. Dropdown options come from the page. The model has to choose from the real list, so if a <select> enumerates actual records — customers, patients, account names — those option labels are part of the request. This is unavoidable given what the feature does.

2. Providers behind OpenRouter's :free models may log prompts and use them to improve their models, and free models can be withdrawn at any time.

Taken together, treat the free models as public. They are suited to scratch, demo and staging forms. Do not use them on pages containing personal, confidential, regulated or otherwise sensitive data. For that, pick a paid model and confirm that provider's data-retention terms meet your requirements.

What is stored, and where

Your settings (API key, chosen model, options) and any instructions you save live in chrome.storage on your own machine, synced by Chrome if you have sync enabled. The generated values are never recorded — not by the extension, and nowhere off your device. There is no account, no sign-up and no identifier of any kind.

What the permissions are for

PermissionWhy it is needed
scripting To read the form fields and write generated values into them. Some component libraries only respond to events fired from the page's own context, so this runs in the main world.
storage To remember your provider, model and saved instructions between sessions.
host_permissions: <all_urls> The extension is for filling whatever form you happen to be testing, which cannot be known ahead of time. It reads a page only when you open its panel and press Analyze & Fill, or press the per-field ✨ button. It does nothing on pages you never invoke it on.

Children

This is a developer and QA tool. It is not directed at children and collects no data from anyone.

Changes

If what the extension transmits ever changes, this page and the in-product Settings → Privacy summary will be updated together, and the date at the top will change.

Contact

Questions or concerns: open an issue on the project's repository, or contact the developer listed on the extension's Chrome Web Store page.

The same summary is available inside the extension under Settings → Privacy, so you can check it without leaving the page you are on.
